A-Share Stock Data API

Free Real-time & Historical A-Share Stock Market API

免费、实时、无需注册的 A 股市场数据 API。为量化交易者、开发者和金融研究人员打造。
A free, real-time, no-registration-required API for Chinese A-share stock data. Built for quants, developers, and financial researchers.

⚡ Real-time 🐍 Python + FastAPI 🎯 A-Share / A股 📦 No Auth Required 🌐 Open Source

📘 简介 · Introduction

A-Share Stock Data API 提供中国A股市场的实时行情和历史数据，覆盖全部沪深京上市公司。 数据来源于腾讯财经和东方财富，无需注册或 API Key，开箱即用。
The A-Share Stock Data API provides real-time quotes and historical data for the Chinese A-share market, covering all Shanghai, Shenzhen, and Beijing listed companies. Data sourced from Tencent Finance and East Money (东方财富). No registration or API Key required.

⚡ 快速开始 · Quick Start

最简单的调用方式 — 只需一个 cURL 命令即可获取实时行情数据。

cURL

GET /history/{code} 历史数据 · Historical Daily Data
获取股票的历史日K线数据。支持前复权（qfq）和后复权（hfq）调整。
Get historical daily OHLC data. Supports forward (qfq) and backward (hfq) price adjustment.
参数 类型 必填 说明
code string Required 股票代码（路径参数）
start string Optional 开始日期，格式 YYYYMMDD。默认一年前
end string Optional 结束日期，格式 YYYYMMDD。默认今天
adjust string Optional 复权类型：空字符串（不复权）、qfq（前复权）、hfq（后复权）

📋 响应格式 · Response Format

所有端点返回统一的 JSON 响应结构，并在 HTTP 响应头中包含打赏信息。

JSON Body 结构 · JSON Response Structure

字段 类型 说明
status string "ok" 或 "error"
Request status indicator
data object|array 具体的响应数据，根据端点不同而变化
The actual response payload, varies by endpoint
count number 返回的记录数（仅 /history 和 /search 端点）
Number of records returned (only /history and /search)
error string 错误详情（仅在 status 为 "error" 时出现）
Error details (only when status is "error")
donation object 打赏地址信息
Donation address information

HTTP 响应头 · Response Headers

Header 值 说明
X-Donation-Address string BSC 钱包地址
BSC wallet address for donations
X-Donation-Network string 网络类型：BSC (BEP-20)
Donation network
X-Powered-By string Hermes Agent + binglewu

⚠️ 错误处理 · Error Handling

当请求失败时，API 会返回带有 status: "error" 的 JSON 响应。常见错误原因：
When a request fails, the API returns a JSON response with status: "error". Common error causes:
场景 HTTP 状态码 响应
无效股票代码 200 {"status": "error", "error": "parse_failed", ...}
缺少必要参数 400 {"detail": "Provide 'codes' in JSON body or query params"}
数据源超时 200 {"status": "error", "error": "timeout error", ...}

💻 使用示例 · Usage Examples

多种编程语言的调用示例，助您快速集成。

Python · requests 
import requests

BASE_URL = "https://ashare.binglewu.workers.dev"

# 实时行情 · Real-time quote
resp = requests.get(f"{BASE_URL}/quote/600519")
data = resp.json()
print(f"茅台股价: {data['data']['price']} 元")

# 历史数据 · Historical data
resp = requests.get(
    f"{BASE_URL}/history/000001",
    params={"start": "20250101", "adjust": "qfq"}
)
records = resp.json()["data"]
print(f"共 {len(records)} 条记录")

# 批量查询 · Batch query
resp = requests.post(
    f"{BASE_URL}/batch",
    json={"codes": ["600519", "000001", "300750"]}
)
print(resp.json()["data"])
JavaScript · fetch 
const BASE_URL = "https://ashare.binglewu.workers.dev";

// 实时行情 · Real-time quote
const quote = await fetch(`${BASE_URL}/quote/600519`).then(r => r.json());
console.log(`茅台股价: ${quote.data.price} 元`);

// 历史数据 · Historical data
const history = await fetch(
    `${BASE_URL}/history/000001?start=20250101&adjust=qfq`
).then(r => r.json());
console.log(`共 ${history.count} 条记录`);

// 批量查询 · Batch query
const batch = await fetch(`${BASE_URL}/batch`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ codes: ["600519", "000001"] })
}).then(r => r.json());
console.log(batch.data);

Rust · reqwest 
use reqwest::Client;
use serde_json::Value;

async fn get_quote() -> Result<(), Box<dyn std::error::Error>> {
    let client = Client::new();

    // 实时行情 · Real-time quote
    let resp: Value = client
        .get("https://ashare.binglewu.workers.dev/quote/600519")
        .send().await?
        .json().await?;
    println!("茅台股价: {}", resp["data"]["price"]);

    // 批量查询 · Batch query
    let batch: Value = client
        .post("https://ashare.binglewu.workers.dev/batch")
        .json(&serde_json::json!({
            "codes": ["600519", "000001"]
        }))
        .send().await?
        .json().await?;
    println!("{:#?}", batch["data"]);

    Ok(())
}
